# Lampshade 💡

**Lampshade** یک پروژه چندبخشی و ماژولار است که با هدف پیاده‌سازی بخش‌های مختلف یک سیستم نرم‌افزاری با ساختار منظم و قابل توسعه طراحی شده است.  
این پروژه شامل قسمت‌های مختلفی در فرانت‌اند، بک‌اند و لایه‌های دامنه و زیرساخت است و تلاش شده تا کدها به صورت تفکیک‌شده و قابل نگهداری سازمان‌دهی شوند 🚀

---

## معرفی پروژه

Lampshade مجموعه‌ای از ماژول‌ها و لایه‌های مختلف را در خود جای داده است که برای مدیریت بخش‌هایی مثل:

- مدیریت حساب کاربری
- مدیریت وبلاگ
- مدیریت نظرات
- مدیریت تخفیف
- مدیریت موجودی
- مدیریت فروشگاه

طراحی شده‌اند. این ساختار نشان می‌دهد پروژه فقط یک برنامه ساده نیست، بلکه یک سیستم چندبخشی و قابل توسعه است 👌

---

## ویژگی‌های خاص پروژه ✨

- **معماری ماژولار** برای نگهداری بهتر و توسعه راحت‌تر
- **تفکیک لایه‌ها** بین Application، Domain، Infrastructure و Presentation
- **پشتیبانی از چند بخش مستقل** مثل Account، Blog، Comment، Discount، Inventory و Shop
- **وجود FrontEnd جداگانه** برای بخش رابط کاربری
- **استفاده از C# و JavaScript** در کنار HTML و CSS
- **مناسب برای توسعه پروژه‌های بزرگ‌تر** و تیمی
- **ساختار حرفه‌ای‌تر نسبت به پروژه‌های معمولی دانشجویی** 😎
- **سیستم احراز هویت کامل و Role-Based (مبتنی بر نقش)**  
- **قابلیت تعریف سطح دسترسی جداگانه برای هر کاربر**
- **دارای امکانات کامل فروشگاهی از جمله درگاه پرداخت**

---

## سیستم احراز هویت و دسترسی 🔐

در این پروژه، سیستم احراز هویت به صورت کامل پیاده‌سازی شده و دسترسی‌ها **بر اساس نقش** مدیریت می‌شوند.  
علاوه بر نقش‌ها، برای هر شخص می‌توان دسترسی‌ها را **به‌صورت مجزا و دقیق** تعریف کرد تا کنترل کامل روی بخش‌های مختلف سیستم وجود داشته باشد.

---

## امکانات فروشگاهی و پرداخت 💳

Lampshade از نظر امکانات کاربردی کامل طراحی شده و علاوه بر مدیریت بخش‌های اصلی فروشگاه، شامل قابلیت‌های مرتبط با خرید و پرداخت نیز هست.  
پشتیبانی از **درگاه پرداخت** هم در ساختار پروژه در نظر گرفته شده است.
